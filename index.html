Concept & Definition

A Stack is a linear data structure following the LIFO (Last In First Out) principle. The element added last is the first one to be removed. All insertions and deletions take place at a single end called the TOP.

Key Conditions:
  • Overflow: Occurs when attempting to push onto a stack that has reached maximum capacity.
  • Underflow: Occurs when attempting to pop or peek from an empty stack.

Concept & Definition

A Queue is a linear collection governed by the FIFO (First In First Out) principle. The element inserted earliest is removed first. New elements enter at the Rear, while elements depart from the Front.

Key Conditions:
  • Queue Overflow: When trying to enqueue into a queue with maximum elements.
  • Queue Underflow: When attempting to dequeue or read front/rear from an empty queue.

Concept & Definition

A Singly Linked List is a linear dynamic data structure composed of self-referential Nodes. Each node stores a data value and a pointer (next) pointing to the successor node. The last node points to NULL.

Pointer Invariants:
  • Head: Address of the very first node.
  • Dynamic Sizing: Does not require contiguous memory or fixed preallocated arrays.
  • Sequential Traversal: Direct index access is not possible; elements must be traversed sequentially from Head.

Concept & Definition

A Binary Search Tree (BST) is a node-based binary tree data structure which has the following properties:

  • The left subtree of a node contains only keys less than the node's key.
  • The right subtree of a node contains only keys greater than the node's key.
  • Both left and right subtrees must also be binary search trees.
  • Duplicate keys are strictly disallowed.

Traversals Explained

  • Inorder (Left → Root → Right): Yields keys in ascending sorted order.
  • Preorder (Root → Left → Right): Used for cloning trees and prefix notation.
  • Postorder (Left → Right → Root): Used for bottom-up node deallocation and postfix math.

Project Objective

To bridge theoretical data structure lectures with hands-on, interactive visual feedback. Students can inspect each step of fundamental algorithms, observe pointer transitions, and correlate animations with real-world time and space complexities.

Technologies Used

  • HTML5: Semantic document structure and SVG canvas elements.
  • CSS3: Responsive CSS Grid/Flexbox, transitions, custom properties and dark mode theme.
  • Vanilla JavaScript (ES6+): State management, algorithmic step tracing, and visual rendering without external libraries.
  • ISO Standard C++: Modular header files (.h) and source implementations (.cpp).

Key Project Features

  • Complete operational coverage: Push, Pop, Peek, Enqueue, Dequeue, Insert (Head/Tail), Delete, Search, and 3 Tree Traversals.
  • Edge-case validation: Empty inputs, boundary checks, duplicate BST values, stack/queue overflow & underflow.
  • Live Execution Tracer: Logs algorithmic micro-steps for clear grading demonstration.
  • Zero-dependency portability: Double-click index.html to run anywhere.

Verification & Testing Instructions

  1. Browser Testing: Double-click index.html in any web browser (Chrome, Edge, Firefox, Brave, Safari).
  2. Interactive Verification: Use the sidebar to visit each module. Try normal values, boundary values (empty input, duplicates), and reset buttons.
  3. C++ Verification: Open the cpp/ folder. If a C++ compiler (like g++) is available, compile with: g++ main.cpp stack.cpp queue.cpp linkedlist.cpp bst.cpp -o dsa_demo and run ./dsa_demo.
